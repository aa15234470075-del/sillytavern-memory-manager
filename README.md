# 酒馆记忆管理器 · 自用测试版

SillyTavern 前端扩展：按楼层提取剧情，生成可人工核对的短期、长期和固定记忆，并在创作主模型请求前按本地关键词注入。当前源码版本为 v0.5.6，供自用和亲友测试，功能与界面仍在调整中。

v0.5.4 将导航整理为“记忆、总结、待确认、记忆整理、日志”，设置通过面板右上角 ⚙ 进入。× 仅关闭面板；插件总开关位于设置顶部，关闭后停止自动任务与记忆注入。老版配置首次升级会重置并提示重新配置，聊天记忆和角色共享记忆保留。

v0.5.5 整理筛选备选、设置顺序和可折叠说明，强化总结任务与输出格式边界，区分模型返回普通文字和损坏结构；不缩减原文、不新增隐式重试。本轮不重置 v0.5.4 设置。逐项结果见 [V055-验收反馈.md](V055-验收反馈.md)。

## 能力

v0.5.6 增加批次进度与失败暂停、按聊天恢复草稿和队列、关键词补齐、新手引导、记忆条数控制及按自己意见重新生成；保存后同步手动／自动／批量起点。修复流式完成等待和会话令牌问题，未裁剪输入或新增隐式重试。本次只部署云酒馆，GitHub尚未更新。逐项结果见 [V056-验收反馈.md](V056-验收反馈.md)。

- 按楼层预览正文、来源范围和字符数；白名单与黑名单可同时使用。
- 生成后先进入草稿，支持编辑、多选归类、归档、删除和版本切换。
- 短期记忆直接发送；长期记忆使用本地关键词门槛，并支持短版衔接；固定记忆单独保存。
- 重要原话逐字核对，无法核对的内容只保留为待核对项，不注入主模型。
- AI 检查意见与记忆正文分离；字段位置类意见作为全局意见显示。
- 严格 JSON、stm4 专用标签、简单分段三种输出格式。格式修复是用户可选的单次额外调用，不会自动换模型。
- 总结、检查、格式修复分别支持独立 API、模型和流式开关；密钥默认保存在当前浏览器，并支持本地连接预设。
- 日志记录材料、请求、返回、解析、检查和注入过程，支持复制、导出和清理。
- 支持角色共享阁楼、设置存档、预设条目组导入导出，以及酒馆原生楼层隐藏。
- 可用滑块、颜色选择和下拉选项调节三层按钮、面板字号、间距和圆角；改动立即预览，保存设置后持久保留。
- 支持手动新增短期、长期、固定记忆，长期记忆可填写关键词与短版。

## 安装

在酒馆的“扩展”中选择“安装扩展”，粘贴本项目所在仓库的地址。

```text
https://github.com/baobao449/sillytavern-memory-manager
```

刷新酒馆后，从扩展入口打开“酒馆记忆管理器”。手动安装时需保留整个仓库的运行文件，不能只复制入口文件。

首次使用时在设置中填写独立 API 地址、密钥和模型；地址应填写到 `/v1`。密钥不会写入记忆、日志、预设或导出文件。

## 使用流程

1. 点 ⚙ 配置 API、模型和正文筛选，点击保存设置。密钥只保存在当前浏览器。
2. 在“总结”页选择手动、自动或高楼层批量。自动参数在设置中，当前状态与开始／暂停在总结页。
3. 手动选择起止楼层，查看分楼层正文和最终请求；两种预览再次点击可收起。也可选择生成后直接保存及保存类别。
4. 需要确认的结果进入“待确认”。展开记忆正文核对；首版可按设置检查一次。按意见重新生成会带上检查意见，新版本不再次检查；普通重新生成不携带旧稿或意见。旧版本可切换。
5. 保存后在“记忆”页按短期、长期、固定查看，也可在“记忆整理”页按首次、二次、三次整理。选择首次结果生成二次，选择二次结果生成三次。
6. 隐藏只在保存通过服务端核验后进行，每个范围保留最近指定条数。总结页顶部显示已保存、隐藏、未总结范围。
7. 批量先选择范围和每批数量，预览后开始。人工模式每批确认后点继续；AI模式自动分类保存；混合模式只在指定类别停下确认。失败暂停并保留队列，可重试、跳过或停止。刷新后恢复本浏览器待确认草稿和队列，恢复队列保持暂停，不自动调用；清理浏览器数据会清除本地恢复副本。
8. “日志”分任务记录和向主模型发送记忆两个入口，各自刷新、复制、导出与清理。发送记录仅包含插件记忆；“准备注入”不代表已由上游收到。

界面隐藏并不停止自动总结；自动结果需要确认时会重新打开待确认页。首次检查失败时保留草稿，不自动保存或隐藏。模型修改是否正确仍需结合原文核对，插件不将文字变化冒称为事实改善。

记忆标题折叠时也可以勾选。分类按钮有选择则处理选择项，没有选择则处理当前列表全部，删除／归档仍必须明确勾选。长期记忆缺关键词时会提示，可手动、本地提取或一次API补齐缺失项。总结条数和自己的修改意见可在总结／重新生成入口选择。新手引导可跳过，并在设置重新打开。

## 开发与验证

```powershell
npm test
```

测试覆盖严格 JSON、标签和分段格式、来源校验、检查格式修复、重试次数、删除和归档、隐藏尾部、日志清理以及 390px/1280px 窄宽屏流程。真实剧情质量和上游 API 延迟仍需在用户自己的环境中验证。

## 数据范围与回退

聊天记忆保存在当前聊天元数据；角色阁楼只保存用户主动共享的内容。日志和操作备份保存在当前浏览器。服务器部署前会创建独立回退目录。

本项目不包含测试密钥、API 地址凭据或用户聊天正文。

## v0.5.0

- 首次、二次、三次及检查使用不同资料优先级，允许自行调整。人设和世界书不能自动变成本次剧情事实。

- 二、三次总结每条选中记忆只打包一次，同时继承全部来源；重要原话只继承可核实的角色回复。

自定义按钮可使用 `#smm-panel [data-button-level="1"]`、`[data-button-level="2"]`、`[data-button-level="3"]`；危险操作另有 `[data-danger="true"]`。插件主题提供 `--smm-button-1-bg`、`--smm-button-2-color` 等变量。不会新增备用 API，也不会自动切换模型；重试仍按用户填写的次数执行。

时间检测只能发现部分没有逐字来源的明确日期/时刻，不能代替语义核查；地点和剧情边界由提示词及可选 AI 检查共同核对。资料或模型输出存在歧义时仍需人工确认。
